1. Konsep Dasar Pemrograman Web

   Cara bikin website yang bisa diakses lewat browser.

2. Arsitektur Klien-Peladen
   
   Klien (browser) minta data, Peladen (server) yang nyimpen dan ngasih datanya.

3. HTTP Request dan Response
   
   Request itu permintaan dari klien, Response itu balasan dari server.

4. HTML, CSS, JavaScript, PHP, MySQL
   
   HTML isi halaman, CSS tampilan, JS interaktif, PHP logika di server, MySQL tempat nyimpen data.

5. Hubungan Antarteknologi

   HTML-CSS-JS jalan di browser, PHP-MySQL jalan di server, saling kirim data lewat HTTP.
